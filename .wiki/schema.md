# 정지훈 포트폴리오 작업 위키 Topic Guide

## State

- schema_state: advisory

## Entity Types

| Type | Meaning |
|---|---|
| phase | 순서가 있는 상위 목표 단계 |
| task | 현재 또는 이후에 수행할 구체적 작업 |
| decision | 사용자와 합의한 디자인 및 콘텐츠 기준 |
| evidence | 이력서, 기술소개서, 프로젝트 자료처럼 주장 근거가 되는 자료 |

## Relationship Verbs

- depends-on
- implements
- supports
- supersedes

## Source Conventions

- 이 위키의 현재 로드맵은 사용자 지시와 저장소의 구현 상태를 바탕으로 작성한다.
- 이력서, 기술소개서, 노션의 새 자료는 확인한 뒤에만 프로젝트 설명이나 자기소개서 근거로 반영한다.
- 공개 포트폴리오에는 NDA 프로젝트의 비공개 구현 세부 내용을 기록하지 않는다.

## Compile Guidance

- 뭘 해야 되는지 묻는 질문에는 로드맵의 현재 다음 행동과 상태가 진행 중인 가장 이른 단계를 먼저 제시한다.
- 완료 기준이 충족되지 않았거나 사용자의 확인이 필요한 일은 완료로 바꾸지 않는다.
